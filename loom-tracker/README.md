# מעקב צפיות בסרטון (go.ezpath-ai.com)

שירות קטן שנותן לכל נמען קישור אישי לסרטון Loom, רושם מתי הוא לחץ, ומפנה אותו לסרטון.
התצוגה המקדימה של וואטסאפ (ובוטים אחרים) לא נספרת כקליק.

| מה | כתובת |
|---|---|
| דשבורד | https://go.ezpath-ai.com/admin |
| קישור אישי | https://go.ezpath-ai.com/v/k7m2qa8x |

השירות רץ על Cloudflare Workers ו-D1, בתוכנית החינמית (100,000 בקשות ביום, הרבה מעבר למה שצריך).
האתר הראשי ezpath-ai.com והקישורים ללקוחות ב-r.ezpath-ai.com לא מושפעים בכלל.

## התקנה ופריסה (פעם אחת, מהמחשב שלך)

צריך Node.js גרסה 20 ומעלה. פותחים טרמינל בתיקייה `loom-tracker` ומריצים לפי הסדר:

**1. התקנת הכלים**
```bash
npm install
```
מתקין את wrangler (הכלי של Cloudflare) ואת TypeScript, רק בתוך התיקייה הזו.

**2. התחברות ל-Cloudflare**
```bash
npx wrangler login
```
נפתח דפדפן, מאשרים. זה מחבר את הטרמינל לחשבון Cloudflare שבו נמצא ezpath-ai.com.

**3. יצירת הטבלאות בבסיס הנתונים**
```bash
npx wrangler d1 migrations apply ezpath-loom-tracker --remote
```
בסיס הנתונים `ezpath-loom-tracker` כבר נוצר בחשבון שלך. הפקודה הזו יוצרת בו את הטבלאות. עונים `y` כשהוא שואל.

**4. הגדרת הסודות** (כל פקודה תבקש להדביק ערך)
```bash
npx wrangler secret put LOOM_URL
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put IP_SALT
```
- `LOOM_URL`: קישור השיתוף של הסרטון ב-Loom, למשל `https://www.loom.com/share/abc123...`
- `ADMIN_PASSWORD`: סיסמה לדשבורד. ארוכה, לפחות 12 תווים.
- `IP_SALT`: מחרוזת אקראית שמשמשת להצפנה חד-כיוונית של כתובות IP. ליצירה: `node -e "console.log(crypto.randomUUID())"`

הסודות נשמרים מוצפנים ב-Cloudflare ולא בקוד. אם wrangler שואל אם ליצור Worker חדש, עונים כן.

**5. פריסה**
```bash
npx wrangler deploy
```
זה מעלה את הקוד ויוצר אוטומטית את `go.ezpath-ai.com` כולל תעודת SSL. לפעמים לוקח דקה או שתיים עד שהכתובת עונה.

לעדכון קוד בעתיד מספיק להריץ שוב `npx wrangler deploy`.

## חיבור הדומיין

אין מה לעשות ידנית. הדומיין כבר מנוהל ב-Cloudflare, וב-`wrangler.toml` מוגדר:
```toml
routes = [{ pattern = "go.ezpath-ai.com", custom_domain = true }]
```
בפריסה הראשונה Cloudflare יוצר את רשומת ה-DNS של `go` ואת תעודת ה-SSL.

## הוספת נמענים ושליחה

1. נכנסים ל-https://go.ezpath-ai.com/admin עם הסיסמה.
2. ב"יצירת קישורים" מדביקים רשימה, שורה לכל נמען:
   ```
   מרפאת שיניים כהן, 050-1234567
   ד"ר לוי	054-7778899
   ```
   פסיק או טאב (העתקה מאקסל עובדת). הטלפון אופציונלי. אפשר להוסיף עמודה שלישית כהערה.
3. לוחצים "צור קישורים". לכל נמען נוצר קוד אקראי קצר וקישור אישי.
4. לכל שורה: "העתק" לקישור, או "וואטסאפ" שפותח שיחה עם ההודעה מוכנה (את נוסח ההודעה עורכים בדף, `{שם}` ו-`{קישור}` מוחלפים אוטומטית).

מספרי טלפון מנורמלים לפורמט בינלאומי: `050-1234567` הופך ל-`972501234567`.

### סרטון אחר לנמען מסוים (אופציונלי)
ברירת המחדל היא `LOOM_URL` לכולם. כדי לשלוח נמען מסוים לסרטון אחר:
```bash
npx wrangler d1 execute ezpath-loom-tracker --remote --command "UPDATE recipients SET target_url='https://www.loom.com/share/OTHER' WHERE id='k7m2qa8x'"
```

## איך סופרים קליקים

- כל כניסה ל-`/v/{id}` נרשמת בטבלה `clicks`: מזהה, זמן (UTC, מוצג בשעון ישראל), user-agent, מדינה, ו-IP מוצפן (SHA-256 עם `IP_SALT`, ה-IP עצמו לא נשמר).
- **בוטים נרשמים אבל לא נספרים:** התצוגה המקדימה של וואטסאפ, פייסבוק, טלגרם, סלאק, לינקדאין, גוגל, curl, דפדפנים אוטומטיים, בקשות HEAD ו-prefetch. גם הם מופנים לסרטון כרגיל, כדי שהתצוגה המקדימה בוואטסאפ תציג את הסרטון.
- ההפניה לא מחכה לרישום, ועובדת גם אם הרישום נכשל.
- כל מזהה תקין מקבל בדיוק אותה תגובה, כך שאי אפשר לגלות אם מזהה קיים. מזהה לא תקין מקבל 404 רגיל.
- אין עוגיות אצל הצופה.

## אבטחה

- `/admin` דורש סיסמה. אחרי כניסה נשמרת עוגייה חתומה ל-30 יום. החלפת `ADMIN_PASSWORD` מנתקת את כל החיבורים.
- 5 סיסמאות שגויות מאותו IP חוסמות ל-15 דקות.
- `robots.txt` חוסם את `/admin` ואת `/v/`.

## הרצה ובדיקה מקומית

```bash
cp .dev.vars.example .dev.vars          # וממלאים ערכי בדיקה
npm run db:migrate:local
npm run dev                              # http://127.0.0.1:8787/admin
ADMIN_PASSWORD=... LOOM_URL=... scripts/smoke.sh
```
`smoke.sh` בודק: קליק רגיל נספר פעם אחת, בוטים/HEAD/prefetch לא נספרים, מזהה לא תקין מחזיר 404, `/admin` חסום בלי סיסמה, וחסימה אחרי 5 ניסיונות.

## רשימת בדיקה אחרי הפריסה (מהטלפון)

1. נכנסים ל-`/admin`, יוצרים נמען בשם "בדיקה" עם המספר שלך.
2. לוחצים "וואטסאפ" ושולחים לעצמך (או מעתיקים את הקישור ושולחים לעצמך בצ'אט "הודעה לעצמי").
3. מחכים שהתצוגה המקדימה תופיע בצ'אט, **בלי ללחוץ**. מרעננים את הדשבורד: "בדיקה" עדיין 0 עם "עוד לא לחץ".
4. לוחצים על הקישור בוואטסאפ. הסרטון נפתח ב-Loom.
5. מרעננים את הדשבורד: "בדיקה" עם 1 קליק, עם השעה הנכונה ומדינה IL.
6. פותחים את `https://go.ezpath-ai.com/admin` בחלון גלישה בסתר: צריך לבקש סיסמה.
