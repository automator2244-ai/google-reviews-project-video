# תמלולים מערוצי יוטיוב

נותנים לכלי ערוץ יוטיוב, והוא מוריד את התמלולים של הסרטונים לאט ובזהירות, שומר אותם כאן ב-`channels/` ומעלה ל-GitHub לבד. אחר כך פשוט שואלים את Claude בצ'אט שאלות על הערוץ, והוא עונה לפי התמלולים עם קישור לדקה המדויקת בסרטון.

הכלי רץ על המחשב שלך ולא בענן, כי יוטיוב חוסם תמלולים לשרתים בענן כמעט מיד.

## התקנה (פעם אחת)
פותחים את **Terminal** (או "שורת הפקודה") ב-Windows ומריצים:

```
winget install Python.Python.3.12
winget install Git.Git
```

סוגרים את החלון ופותחים חדש, ואז:

```
cd %USERPROFILE%\Documents
git clone https://github.com/automator2244-ai/google-reviews-project-video.git
```

בפעם הראשונה ש-Git מעלה משהו ל-GitHub נפתח חלון התחברות בדפדפן. מתחברים פעם אחת וזהו.

## הרצה
```
cd %USERPROFILE%\Documents\google-reviews-project-video\youtube-transcripts
git pull
yt @channelname
```

| מה רוצים | הפקודה |
|---|---|
| כל הסרטונים בערוץ | `yt @channelname` |
| 50 הסרטונים החדשים ביותר שעוד לא ירדו | `yt @channelname --limit 50` |
| 50 הראשונים (הישנים ביותר) | `yt @channelname --limit 50 --oldest` |
| גם Shorts | להוסיף `--include-shorts` |
| גם שידורים חיים שהסתיימו | להוסיף `--include-streams` |
| לנסות שוב סרטונים שלא היה להם תמלול | להוסיף `--retry-missing` |
| מה ירד עד עכשיו | `yt status` |

אפשר גם להדביק קישור מלא לערוץ במקום `@channelname`.

בפעם הראשונה ההרצה מתקינה לבד את מה שצריך (דקה בערך). ההודעות בחלון באנגלית בכוונה, כי החלון של Windows מציג עברית הפוך.

## איך הוא נמנע מחסימה
- בין סרטון לסרטון הוא מחכה זמן אקראי של 20 עד 60 שניות.
- כל 25 סרטונים הוא לוקח הפסקה של 5 עד 10 דקות.
- אם יוטיוב בכל זאת מגביל, הוא מחכה 15 דקות, אחר כך 30, אחר כך שעה. אם עדיין חסום, הוא שומר הכל ועוצר, ואומר להריץ שוב מחר.
- ערוץ של 200 סרטונים לוקח בערך שלוש שעות. אפשר להשאיר את המחשב לעבוד (רק שלא ייכנס למצב שינה).

## עצירה והמשך
אפשר לעצור בכל רגע עם `Ctrl+C`. כל סרטון נשמר מיד כשהוא יורד, אז מריצים שוב את אותה פקודה וזה ממשיך מאיפה שעצר. סרטונים שכבר ירדו לא יורדים שוב.

ההעלאה ל-GitHub קורית כל 20 סרטונים ובסוף, כך שאפשר להתחיל לשאול שאלות עוד לפני שערוץ ארוך הסתיים.

## שאלות
פשוט שואלים את Claude בצ'אט, למשל: "לפי הערוץ של X, מה הוא ממליץ לעשות כשלקוח מבקש הנחה?". Claude מושך את התמלולים מ-GitHub, מחפש בהם ועונה עם קישורים לסרטונים.

## מה יש בתיקייה
- `yt.bat`: מה שמריצים.
- `yt_transcripts.py`: ההורדה.
- `search.py`: חיפוש בתמלולים (Claude משתמש בו כדי לענות).
- `channels/<ערוץ>/`: לכל ערוץ `channel.json` (פרטי הערוץ), `videos.jsonl` (כל סרטון והסטטוס שלו), וקובץ `.md` לכל סרטון עם התמלול בפסקאות של חצי דקה וחותמות זמן.
