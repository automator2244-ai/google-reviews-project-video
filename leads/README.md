# לידים של רופאי שיניים (Google Sheets)

הגיליון: [לידים רופאי שיניים](https://docs.google.com/spreadsheets/d/13bRjc6ezK3SAYv4YQFW8SEUj3FYZdTM-Frg3Hlb_xS8/edit)

## מה זה עושה
- **שתי לשוניות:** "עסקי" (וואטסאפ עסקי) ו"מאובטח" (וואטסאפ בתיקייה המאובטחת).
- **מילוי אוטומטי:** כל ראשון עד חמישי, בסביבות 07:00, נוספות 40 מרפאות חדשות לכל לשונית, עם שורה ריקה לפני כל קבוצה חדשה.
- **מקור הנתונים:** הכל מגיע מ-Google Places. מה שגוגל לא מחזיר (אתר, דירוג) נשאר ריק.
- **רק טלפון נייד (05x).** מרפאות עם טלפון קווי נשמרות בלשונית המוסתרת `_נסרקו` ולא נכנסות לרשימה.
- **אין כפילויות:** אף טלפון לא נכנס פעמיים, לא באותה לשונית ולא בשתיהן. טלפון כפול שמוקלד ידנית נצבע באדום.
- **סטטוס:** עוד לא נשלחה הודעה, נשלחה הודעה, נשלח סרטון, נקבעה שיחה, לקוח חדש. לכל סטטוס צבע שורה אחר.
- **סינון:** כפתור הסינון בכותרת של "סטטוס".
- **וואטסאפ:** "פתח צ'אט" פותח שיחה עם המרפאה. הוא נפתח בוואטסאפ של המקום שממנו לחצת (רגיל או תיקייה מאובטחת).
- **לשונית "הגדרות":**
  - רשימת האזורים לפי הסדר. אפשר להוסיף ולשנות סדר. אזור שסומן "נסרק" לא ייסרק שוב.
  - מצב המערכת: ריצה אחרונה, כמה נוספו, וחיפושים החודש.

## תקרות (כדי לא לשלם לגוגל)
- **25 חיפושים בריצה, 900 בחודש.** זה מתחת ל-1,000 החינמיים של גוגל.
- **עודפים:** מרפאות שנמצאו מעבר ל-40 נשמרות בלשונית `_תור` ונכנסות ראשונות בפעם הבאה.

## התקנה (פעם אחת)
1. בגיליון: **Extensions** (תוספים), ואז **Apps Script**.
2. מוחקים את מה שכתוב שם, מדביקים את כל התוכן של `leads.gs`, ושומרים (סמל הדיסקט).
3. בצד שמאל: **Project Settings** (גלגל השיניים), ואז **Script properties**, ואז **Add script property**:
   - Property: `PLACES_KEY`
   - Value: מפתח Google Places
   - ושומרים.
4. חוזרים ל-**Editor** (סמל `< >`). למעלה בוחרים את הפונקציה `setup` ולוחצים **Run**.
5. גוגל תבקש הרשאות:
   - **Review permissions**, ואז בוחרים את החשבון.
   - אם מופיע "Google hasn't verified this app", לוחצים **Advanced**, ואז **Go to ... (unsafe)**. זה בסדר, זה הסקריפט שלך.
   - לוחצים **Allow**.
6. חוזרים לגיליון ומרעננים. מופיע תפריט **לידים**. לוחצים **מלא עכשיו** לבדיקה ראשונה.

## בדיקות
```bash
node leads/test/run.js
```
בודק עם נתוני דמה של גוגל:
- שדות חסרים נשארים ריקים.
- מרפאות עם קווי, סגורות או בלי טלפון לא נכנסות.
- אותו טלפון בפורמטים שונים מזוהה ככפילות.
- 40 + 40 בכל ריצה, עם תור לעודפים ושורה ריקה בין ימים.
- אין ריצה בשישי ובשבת, ותקרת החודש נשמרת.
- הקלדה ידנית נבדקת מול שתי הלשוניות.
