# סרטונים אישיים עם מעקב (go.ezpath-ai.com)

כל עסק מקבל קישור אישי לדף עם סרטון משלו: חלק אישי שבניה מקליט, ואחריו סרטון התבנית.
בדשבורד רואים מי נכנס לקישור, מתי, אם לחץ Play ועד איפה צפה.
התצוגה המקדימה של וואטסאפ (ובוטים אחרים) לא נספרת.

| מה | כתובת |
|---|---|
| דשבורד | https://go.ezpath-ai.com/admin |
| קישור אישי | https://go.ezpath-ai.com/v/k7m2qa8x |

הכל רץ על Cloudflare בתוכנית החינמית:
- Worker בשם `ezpath-video-links` (הקוד בתיקייה הזו).
- מאגר נתונים D1 בשם `ezpath-loom-tracker` (השם נשאר מהגרסה הראשונה).
- אחסון סרטונים R2 בשם `ezpath-videos`, עם 10GB חינם, שזה מאות סרטונים.

האתר הראשי ezpath-ai.com והקישורים ללקוחות ב-r.ezpath-ai.com לא מושפעים.

## איך זה עובד ביום-יום

1. בניה מקליט את החלק האישי ושולח ל-Claude Code עם שם העסק והטלפון.
2. Claude Code מריץ את `scripts/publish.sh`, שבונה את הסרטון:
   - מאחד את ההקלטה עם סרטון התבנית. אם ההקלטה אופקית, היא מוצבת על רקע מטושטש.
   - מאזן את עוצמת הקול, ומנקה בהקלטה האישית זמזום ורעשי רקע.
   - מאיץ את כל הסרטון לפי 1.2 (הקול נשמע טבעי, רק מהר יותר).
   - מוציא סרטון אנכי ב-1080x1920, דחוס לצפייה מהירה בנייד.
   - יוצר תמונה מקדימה לוואטסאפ מתוך החלק האישי.
3. Claude Code רושם את הנמען ב-D1 דרך חיבור Cloudflare, יחד עם אישור העלאה לשעה אחת.
4. `scripts/upload.sh` מעלה את הסרטון עם האישור ומדפיס קישור אישי וקישור וואטסאפ עם הודעה מוכנה.
5. בניה לוחץ "וואטסאפ" (בהודעה מ-Claude Code או בדשבורד) ושולח.

אין צורך בשום מפתח או סיסמה אצל Claude Code. אישור ההעלאה נוצר לכל סרטון בנפרד, תקף לשעה, ונשמר רק כ-hash.

```bash
scripts/publish.sh --name "מרפאת שיניים כהן" --phone 050-1234567 --personal recording.mp4
# מריצים את out/<id>/register.sql על D1 דרך חיבור Cloudflare, ואז:
scripts/upload.sh <id>
```
| אפשרות | מה עושה |
|---|---|
| `--personal-first` | החלק האישי לפני התבנית (ברירת המחדל: אחריה) |
| `--no-outro` | בלי כרטיס הסיום (ברירת המחדל: הוא בא בסוף, אחרי החלק האישי) |
| `--speed 1` | בלי האצה (ברירת המחדל: פי 1.2) |
| `--sync 0.3` | מתקן איחור קבוע בין הקול לתמונה בהקלטה האישית: 0.3 = הקול מאחר ב-0.3 שניות, מינוס 0.3 = הקול מקדים |
| `--brighten` | מבהיר מעט הקלטה אישית חשוכה |
| `--video file.mp4` | סרטון מוכן, בלי איחוד עם התבנית |
| `--id k7m2qa8x` | מחליף את הסרטון של נמען קיים (הקישור נשאר אותו קישור) |
| `--note "טקסט"` | הערה שמופיעה בייצוא ה-CSV |
| `--local` | רושם ומעלה מיד לסביבת הבדיקה המקומית (`npm run dev`) |

## הדשבורד

- **סיכום:** נמענים, כמה נכנסו לקישור, כמה ניגנו את הסרטון, ואחוז כניסה.
- **טבלה:**
  - כניסות (בלי בוטים) וצפייה ("התחיל", 25%, 50%, 75%, "עד הסוף").
  - כניסה אחרונה וראשונה, בשעון ישראל, ומדינה.
  - מי שעוד לא נכנס מסומן.
- **בכל שורה:** "העתק" לקישור, ו"וואטסאפ" שפותח שיחה עם הודעה מוכנה.
- **נוסח ההודעה:** עורכים בחלק "נוסח הודעה לוואטסאפ". `{שם}` ו-`{קישור}` מוחלפים אוטומטית.
- **חיפוש לפי שם וייצוא CSV.**

## מה נרשם ואיך

- **כניסה לדף `/v/{id}`:** נרשם הזמן, ה-user-agent, המדינה ו-IP מוצפן (SHA-256 עם `IP_SALT`, ה-IP עצמו לא נשמר).
- **בוטים נרשמים אבל לא נספרים:** התצוגה המקדימה של וואטסאפ, פייסבוק, טלגרם וכו', curl, דפדפנים אוטומטיים, HEAD ו-prefetch. הם עדיין מקבלים את הדף, כדי שהתצוגה המקדימה בוואטסאפ תציג את שם העסק ותמונה מהסרטון.
- **אירועי נגן:** הדף שולח אירוע כשלוחצים Play, ב-25%, 50% ו-75%, ובסוף הסרטון.
- **מזהה לא קיים או לא תקין** מקבל את אותו דף "הסרטון לא זמין", כך שאי אפשר לנחש מזהים.
- **אין עוגיות אצל הצופה.**

## אבטחה

## פריסה

Cloudflare מעלה את ה-Worker לבד מ-GitHub (Workers Builds) בכל פעם שהקוד משתנה. ההגדרה נעשית פעם אחת בדשבורד של Cloudflare:
1. Workers & Pages, ואז Create, ואז Import a repository. מחברים את GitHub ובוחרים את `google-reviews-project-video`.
2. Project name: `ezpath-video-links` (חייב להיות בדיוק השם הזה).
3. Root directory: `video-links`. Deploy command: `npx wrangler deploy`.
4. אחרי שה-Worker נוצר: Settings, ואז Variables and Secrets. מוסיפים סוד אחד (Type: Secret):
   - `IP_SALT`: רצף אקראי ארוך של אותיות ומספרים.
5. Settings, ואז Build: מוודאים שהענף הוא הענף שעליו נמצא הקוד.

ב-`wrangler.toml` מוגדר `go.ezpath-ai.com` כ-Custom Domain, ולכן Cloudflare יוצר את רשומת ה-DNS ואת תעודת ה-SSL לבד.
טבלאות מסד הנתונים מתעדכנות דרך חיבור Cloudflare (ראו `migrations/`), לא בזמן הפריסה.

## דף הסרטון במחשב

במסך רחב (וואטסאפ ווב או וואטסאפ למחשב) הרקע בהיר בצבעי המותג, ומשני צדי הסרטון יש כרטיס אחד בכל צד: בצד אחד כרטיס עיצובי מינימליסטי (4.9, כוכבים שנדלקים ועמודות שעולות, בלי תמונות לטעון), ובצד השני כרטיס עם התמונה של בניה, כפתור וואטסאפ עם הודעה מוכנה (כולל שם העסק), טלפון והאתר. בטלפון הדף נשאר רק עם הסרטון. הפרטים והתמונה ב-`src/brand.ts`.

## בדיקה מקומית

```bash
cp .dev.vars.example .dev.vars        # וממלאים ערכי בדיקה
npm run db:migrate:local
npm run dev                            # http://127.0.0.1:8787/admin
```

## רשימת בדיקה אחרי הפריסה (מהטלפון)

1. מעלים סרטון בדיקה עם המספר שלך ושולחים לעצמך את הקישור בוואטסאפ.
2. בודקים שבתצוגה המקדימה מופיעים "סרטון אישי עבור..." ותמונה מהסרטון.
3. **בלי ללחוץ**, מרעננים את הדשבורד: 0 כניסות, עם התגית "עוד לא נכנס".
4. לוחצים על הקישור ומנגנים. אחרי רענון: כניסה אחת, ובעמודת הצפייה מופיע "התחיל" או אחוז.
