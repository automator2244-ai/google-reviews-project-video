# החלק של בניה בסרטון האחיד

`cut.py` חותך את ההקלטה של בניה במשפטים (מקצר הפסקות בין משפטים), מתקן את יחס הגובה-רוחב (הקובץ הגיע אנכי אבל דחוס ל-1080x720), ומחליף בין צילום רחב לצילום קרוב בכל חיתוך. אחר כך החלקים מחוברים, מואצים פי 1.3, ומתחת לקול נכנסת מוזיקה שקטה (Advertime מ-1:08) שיורדת כשבניה מדבר.

הסרטון המלא: `out/final-unified.mp4` = האנימציה (פי 1.2) + החלק של בניה (פי 1.3) + כרטיס הסיום (`cards/outro.html`, 7 שניות, במהירות רגילה), עם מעברים של רבע שנייה.
